# Proposal template — generic v0 (to be tuned)

Rules for whoever fills this in:
- 120–200 words. Clients read the first two lines in the list view; make them count.
- Every claim must come from profile.json or .jobhunt/portfolio/. No invented metrics.
  If a slot has no evidence yet, drop the sentence rather than fill it with a placeholder.
- Mirror the client's own words for the problem; don't restate the whole posting.
- Rate: quote within 45–70 USD/h only if the posting asks; never go below 45.
- Hourly preferred; for a fixed-price posting, offer a short paid first milestone.
